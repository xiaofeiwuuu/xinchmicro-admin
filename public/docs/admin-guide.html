1. 系统介绍

本后台管理系统是一个用于管理产品信息、公司信息、轮播图和用户账户的综合平台。系统主要功能包括：

  • 用户账户管理：创建和管理主账号和子账号
  • 产品信息管理：管理产品分类、目录和详情
  • 公司信息管理：设置公司基本信息、Logo和安全手册
  • 轮播图管理：创建和管理网站首页轮播图
  • 日志管理：查看系统操作日志

系统采用主账号和子账号两级权限管理，主账号拥有所有功能的操作权限，子账号仅能访问部分功能。

2. 登录系统

访问系统登录页面，输入用户名和密码进行登录。

注意：首次登录系统时，请使用管理员提供的初始账号和密码，登录后请立即修改密码。

登录步骤：

1 输入登录信息：
  • 用户名：输入您的账号用户名
  • 密码：输入您的账号密码
2 登录按钮：
  • 点击"登录"按钮提交登录信息
  • 系统会验证您的登录信息

登录成功后，系统会根据您的账号类型（主账号或子账号）显示相应的功能菜单。

3. 账户管理

账户管理功能仅对主账号开放，用于创建和管理子账号。

3.1 创建子账号

主账号可以创建多个子账号，用于分配不同的工作任务。

  1. 在左侧菜单中点击"账户管理"
  2. 点击页面右上角的"创建子账号"按钮
  3. 在弹出的表单中填写用户名和密码
  4. 点击"确定"按钮完成创建

3.2 编辑用户信息

可以编辑用户的基本信息。

  1. 在用户列表中找到需要编辑的用户
  2. 点击"编辑"按钮
  3. 在弹出的表单中修改用户信息
  4. 点击"确定"按钮保存修改

3.3 修改密码

用户可以修改自己的登录密码。

  1. 在用户列表中找到需要修改密码的用户
  2. 点击"修改密码"按钮
  3. 在弹出的表单中输入旧密码和新密码
  4. 点击"确定"按钮完成修改

注意：修改密码需要输入原密码进行验证。

3.4 重置密码

主账号可以为子账号重置密码。

  1. 在用户列表中找到需要重置密码的子账号
  2. 点击"重置密码"按钮
  3. 在弹出的表单中输入新密码
  4. 点击"确定"按钮完成重置

注意：重置密码不需要输入原密码，仅主账号可以操作。

3.5 删除用户

主账号可以删除子账号。

  1. 在用户列表中找到需要删除的子账号
  2. 点击"删除"按钮
  3. 在弹出的确认框中点击"确定"

警告：删除用户操作不可恢复，请谨慎操作。主账号不能删除自己的账号。

4. 产品管理

4.1 产品分类管理

产品分类是产品的最高级分类，用于对产品进行大类划分。

创建产品分类

  1. 在左侧菜单中点击"产品分类"
  2. 点击"新增分类"按钮
  3. 填写分类名称和描述
  4. 点击"确定"按钮完成创建

编辑产品分类

  1. 在分类列表中找到需要编辑的分类
  2. 点击"编辑"按钮
  3. 修改分类信息
  4. 点击"确定"按钮保存修改

删除产品分类

  1. 在分类列表中找到需要删除的分类
  2. 点击"删除"按钮
  3. 在弹出的确认框中点击"确定"

警告：删除产品分类必须删除该分类下的所有产品目录和产品，否则删除不成功，请谨慎操作。

4.2 产品目录管理

产品目录是产品的二级分类，隶属于产品分类。

创建产品目录

  1. 在左侧菜单中点击"产品目录"
  2. 点击"新增目录"按钮
  3. 选择所属分类，填写目录名称和描述
  4. 点击"确定"按钮完成创建

编辑产品目录

  1. 在目录列表中找到需要编辑的目录
  2. 点击"编辑"按钮
  3. 修改目录信息
  4. 点击"确定"按钮保存修改

删除产品目录

  1. 在目录列表中找到需要删除的目录
  2. 点击"删除"按钮
  3. 在弹出的确认框中点击"确定"

警告：删除产品目录必须删除该目录下的所有产品，否则删除不成功，请谨慎操作。

4.3 产品详情管理

产品详情是具体的产品信息，包括产品名称、描述、规格、图片等。

创建产品

  1. 在左侧菜单中点击"产品详情"
  2. 点击"新增产品"按钮
  3. 选择所属目录，填写产品名称、描述、规格等信息
  4. 上传产品图片
  5. 点击"确定"按钮完成创建

编辑产品

  1. 在产品列表中找到需要编辑的产品
  2. 点击"编辑"按钮
  3. 修改产品信息
  4. 点击"确定"按钮保存修改

删除产品

  1. 在产品列表中找到需要删除的产品
  2. 点击"删除"按钮
  3. 在弹出的确认框中点击"确定"

上传产品图片

  1. 在产品编辑页面，点击图片上传区域
  2. 选择要上传的图片文件
  3. 等待图片上传完成
  4. 可以点击"查看"按钮预览上传的图片
  5. 可以点击"修改"按钮更换图片

注意：产品图片支持JPG、PNG等常见图片格式，单个图片大小不超过2MB。

提示：产品删除会查找并删除pdf文件，过程会有点慢，请耐心等待，可刷新列表查看是否删除成功。

5. 公司信息管理

5.1 基本信息设置

设置公司的基本信息，包括公司名称、介绍、联系方式等。

  1. 在左侧菜单中点击"公司信息"
  2. 填写公司名称、公司介绍、联系方式、电子邮箱、公司网站、公司地址等信息
  3. 点击"保存"按钮提交信息

5.2 公司Logo管理

上传和管理公司Logo。

上传Logo

  1. 在公司信息页面，找到"公司Logo"区域
  2. 点击上传区域或"上传"按钮
  3. 选择Logo图片文件
  4. 等待上传完成

查看Logo

  1. 上传Logo后，可以在预览区域看到Logo缩略图
  2. 点击"查看"按钮可以查看高清Logo图片

修改Logo

  1. 点击"修改Logo"按钮
  2. 选择新的Logo图片文件
  3. 等待上传完成

注意：Logo图片建议使用透明背景的PNG格式，分辨率不低于200x200像素，文件大小不超过2MB。

5.3 安全手册管理

上传和管理公司安全手册PDF文件。

上传安全手册

  1. 在公司信息页面，找到"安全手册"区域
  2. 点击"上传PDF文件"按钮
  3. 选择PDF文件
  4. 等待上传完成

下载安全手册

  1. 上传PDF后，点击"下载PDF"按钮
  2. 系统会在新窗口打开PDF文件，可以查看或下载

修改安全手册

  1. 点击"修改PDF"按钮
  2. 选择新的PDF文件
  3. 等待上传完成

注意：PDF文件大小不超过20MB。

6. 轮播图管理

6.1 创建轮播图

创建网站首页的轮播图。

  1. 在左侧菜单中点击"轮播图管理"
  2. 点击"新增轮播图"按钮
  3. 填写轮播图标题和链接
  4. 上传轮播图图片
  5. 设置排序值和状态
  6. 点击"确定"按钮完成创建

注意：轮播图排序值越小，显示位置越靠前。状态可以设置为"启用"或"禁用"。

6.2 编辑轮播图

修改已有轮播图的信息。

  1. 在轮播图列表中找到需要编辑的轮播图
  2. 点击"编辑"按钮
  3. 修改轮播图信息
  4. 点击"确定"按钮保存修改

6.3 查看轮播图

查看轮播图的高清图片。

  1. 在轮播图列表中找到需要查看的轮播图
  2. 点击"查看"按钮
  3. 系统会在弹窗中显示高清图片

6.4 删除轮播图

删除不需要的轮播图。

  1. 在轮播图列表中找到需要删除的轮播图
  2. 点击"删除"按钮
  3. 在弹出的确认框中点击"确定"

警告：删除轮播图操作不可恢复，请谨慎操作。

7. 日志管理

日志管理功能仅对主账号开放，用于查看系统操作日志。

查看日志

  1. 在左侧菜单中点击"日志管理"
  2. 可以通过用户名、操作类型、日期范围等条件筛选日志
  3. 点击"查询"按钮查看筛选结果

日志记录包括用户名、用户类型、请求方法、操作类型、操作时间、请求路径、状态码等信息。

8. 常见问题

Q: 忘记密码怎么办？

A: 根据您的账号类型，有以下解决方案：

  • 子账号用户：
    1. 联系您的主账号管理员
    2. 主账号管理员可以通过"账户管理"页面为您重置密码
  • 主账号用户：
    1. 联系系统管理员
    2. 提供您的账号信息和必要的身份验证
    3. 等待管理员处理您的请求

Q: 上传图片失败怎么办？

A: 请按以下步骤排查：

  1. 检查图片格式是否正确
    • 支持的格式：JPG、PNG、GIF
    • Logo建议使用PNG格式（支持透明背景）
  2. 检查文件大小
    • 普通图片：不超过2MB
    • 轮播图：不超过5MB
  3. 图片分辨率要求
    • Logo：建议200x200像素以上
    • 轮播图：建议1920x1080像素
    • 产品图片：建议800x800像素以上
  4. 如果仍然失败：
    • 尝试压缩图片文件大小
    • 转换图片格式后重试
    • 清除浏览器缓存后重试
    • 联系技术支持获取帮助

Q: 为什么我看不到某些功能菜单？

A: 系统采用基于角色的权限控制：

  • 主账号可见功能：
    • 账户管理
    • 日志管理
    • 所有基础功能
  • 子账号可见功能：
    • 产品管理
    • 公司信息管理
    • 轮播图管理

如果您确认应该看到某个功能但没有看到，请：

  1. 检查您的账号类型
  2. 联系主账号确认权限设置
  3. 尝试退出后重新登录

Q: 上传的文件在哪里查看？

A: 不同类型的文件有不同的查看方式：

  • Logo：
    • 在"公司信息"页面可以直接预览
    • 点击"查看"按钮可以查看原图
  • 轮播图：
    • 在轮播图列表中可以看到缩略图
    • 点击"查看"按钮可以查看大图
  • 产品图片：
    • 在产品详情页面可以查看所有图片
    • 点击图片可以放大查看
  • PDF文件：
    • 点击"下载PDF"按钮可以下载查看
    • 部分浏览器支持直接预览

Q: 系统支持哪些浏览器？

A: 推荐使用以下浏览器及版本：

  • Google Chrome 80+
  • Microsoft Edge 80+
  • Firefox 75+
  • Safari 13+

注意：为了获得最佳使用体验，请确保使用最新版本的浏览器，并保持浏览器更新。
